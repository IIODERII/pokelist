# PokéList
### A react application that displays a list of Pokémon

## Instructions to run the project locally

If you don't have npm installed on your computer download the prebuilt from https://nodejs.org/en/download.

Then download the project and, in the terminal inside the project directory, run:

```bash
npm install
```

After the packages have been installed, run:

```bash
npm run dev
```

Then go to http://localhost:5173/ to open the web page.
